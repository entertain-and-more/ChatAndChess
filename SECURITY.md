# Security Policy

## Deutsch

### Sicherheitsprobleme melden

Bitte keine sensiblen Sicherheitsprobleme öffentlich als normales Issue posten.

Stattdessen:

1. Nutzen Sie GitHub Private Vulnerability Reporting, falls für das Repository verfügbar.
2. Falls das nicht verfügbar ist, öffnen Sie ein minimales GitHub Issue ohne
   technische Details und bitten um einen privaten Maintainer-Kontakt.
3. Beschreiben Sie im privaten Kanal Reproduktion, mögliche Auswirkungen und
   betroffene Dateien.

### Scope

Relevant sind insbesondere:

- Dateibasierte Kommunikation im Claude-Code-Modus
- Umgang mit optionalen API-Zugängen
- Manipulationen an Spielzustand, Worker-Dateien oder lokalen Einstellungen

---

## English

### Reporting Security Issues

Please do not open a normal public issue for sensitive security findings.

Instead:

1. Use GitHub Private Vulnerability Reporting when available.
2. If that is not available, open a minimal GitHub issue without technical
   details and ask for a private maintainer contact.
3. Include reproduction steps, potential impact, and affected files in the
   private channel.

### Scope

Relevant areas include:

- File-based communication in Claude Code mode
- Handling of optional API access
- Tampering with game state, worker files, or local settings
