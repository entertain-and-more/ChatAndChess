THIRD-PARTY LICENSES
====================

Project: ChatAndChess
Audit date: 2026-07-14
Scope: optional Python dependency stack from requirements.txt

Summary
-------

The ChatAndChess base game uses only the Python standard library. The only
declared external dependency is optional:

- anthropic>=0.40.0, used only for Claude API mode in chess.py.

This file is a direct dependency inventory for the optional Claude API stack,
not a complete lockfile or SBOM. Versions below are the resolved versions
observed on 2026-07-14 with:

- python -m pip install --dry-run -r requirements.txt
- local importlib.metadata / PyPI metadata checks
- OSV query for anthropic 0.40.0 and the listed resolved versions

OSV result on 2026-07-14: no advisories were returned for anthropic 0.40.0 or
for the resolved package versions listed below.
